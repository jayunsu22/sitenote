# 현장 후기 탭 + 후기 모아보기 설계

날짜: 2026-09-27
상태: 사용자 승인

## 목적
현장이 끝나면 정해둔 질문(시공후기 / 개선사항 / 견적과 다른 부분)에 답하고 태그를 달아 두고,
나중에 태그·질문별로 모아 보며 다른 현장을 개선한다.

## 결정 사항
| 항목 | 결정 |
|---|---|
| 위치 | 현장 상세 탭 '링크·AS' 오른쪽 **후기** 탭 |
| 질문 | 설정 '후기 질문' 목록. 기본: 시공후기 / 개선사항은 무엇인가? / 견적과 다른 부분은 어떤 것이었나? |
| 태그 | 설정 '현장 태그' 목록. 기본: 도배시공후 / 바닥시공후. 현장당 최대 5개, 후기 탭에서 [+ 태그] 로 바로 추가 |
| 알림 | 시공 날짜가 모두 지났는데 후기(답·태그)가 비어 있으면 후기 탭 빨간 점 |
| 공유 복사 | 후기는 '팀원에게 공유 복사' 에 넣지 않는다 (내부 기록) |
| 모아보기 | 메인 상단 📝 → #reviews 화면. 태그·질문 칩으로 거르기, 최근 시공일 순, 카드 누르면 그 현장 후기 탭 |
| 백엔드 | 변경 없음. 현장·설정은 JSON 통째로 백업(sitenote-sync)되므로 새 칸이 그대로 실린다 |

## 데이터
- 현장: `review = { answers: { [질문문구]: 답 }, tags: [태그…] }` (예전 현장은 빈 값으로 보정)
- 설정: `reviewQuestions: [문구…]`, `reviewTags: [태그…]` — 동기화 대상(SYNCED_SETTINGS·settingsForSync·복원)에 추가
- 답은 질문 문구로 찾는다. 질문을 지우거나 바꿔도 적어 둔 답은 남고, 후기 탭·모아보기에 계속 보인다.

## 순수 함수 (share.js, 테스트)
- `normalizeReview(raw)` — 모양 보정, 태그 중복·빈값 제거, 최대 5개
- `reviewHasContent(site)` — 답 하나라도 있거나 태그가 있으면 true
- `reviewNeeded(site, today)` — 날짜 있는 일차가 모두 today 이전이고 후기가 비었으면 true
- `reviewQuestionsOf(site, questions)` — 설정 질문 + 설정에 없지만 답이 있는 질문
- `collectReviews(sites, { tag, question })` — 후기 있는 현장만, 마지막 시공일 내림차순(날짜 없음은 뒤)

## 검증
- `node test/share.test.js`, `node test/store.test.js`
- 로컬 미리보기(폰 폭): 후기 탭 입력·태그·빨간 점, 모아보기 거르기·이동, 설정 목록
- 배포(push)는 사용자 확인 후. 캐시 버전(?v=, sw CACHE) 올림.
