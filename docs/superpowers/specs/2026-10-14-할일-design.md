# 할 일: 일정 화면에 할 일을 넣고 거래처·현장·AS 와 이어 붙이기

2026-10-14 · 승인된 방향: "새 앱이 아니라 일정 앱(sitenote)에 할 일을 넣는다. 일정 화면에서 날짜별로 현장 카드와 섞어 보여준다(시안 B)."

## 문제

일정 앱에는 현장 일정(날짜·인원·필름·부자재)과 AS 는 있지만, 그 사이에 하는 일 — 거래처 통화, 필름 주문, 밴드 인원 모집, AS 부자재 챙기기 — 을 적을 곳이 없다. 적더라도 결과가 거래처·현장 기록으로 이어지지 않는다.

필요한 네 가지 경우 (사용자 예시):

| 경우 | 연결 | 끝낼 때 |
|---|---|---|
| 내일 1시 거래처 통화, 확인한 내용 기록 | 거래처 | 결과 메모가 거래처 **메모 내역**에 자동으로 쌓인다 |
| 내일 오후 필름 주문 | 현장 | 그 현장 필름 목록을 불러와 보여주고, 주문하면 필름 단계가 '주문'이 된다 |
| 밴드에서 일할 사람 모집 | 현장(선택) | 필요 인원 대비 부족 인원을 보여준다 |
| AS 갈 때 챙길 부자재 | AS | 그 AS 의 부자재·공구 목록을 체크리스트로 보여준다 |

10/5 에 미뤄 둔 '오늘 할 일 화면'(자동 항목 + 직접 넣는 항목을 한 목록에) 논의를 이 설계가 대신한다.

## 결정 사항 (사용자 확인)

1. 거래처에 날짜별로 쌓이는 **메모 내역**을 새로 만든다 (기존 고정 메모 칸 덧붙이기가 아님).
2. 첫 버전에 **직접 넣는 할 일 + 자동 할 일 3종**(필름 주문·인원 모집·부자재 준비)을 한 목록에.
3. 화면은 **시안 B** — 일정 화면에서 날짜별로 현장 카드와 할 일을 섞는다. 밀린 할 일은 맨 위 빨간 상자.
4. 자동 할 일 기준: 필름 주문 시공 3일 전, 인원 모집 시공 3일 전, 부자재 시공·AS 전날. 설정에서 바꿀 수 있다.
5. 할 일 백업은 Airtable 에 '할일' 표를 새로 만들고 n8n "거래처별 현장관리 백업" 워크플로우에 추가한다.

시안 그림: 이 대화에서 보여준 두 장(화면 배치 A/B/C, 넣기·완료·메모 내역). 구현 화면은 시안 B 와 '넣기·완료' 그림을 따른다.

## 설계

### 1. 데이터

#### 1-1. 할 일 `state.tasks[]` (새 목록)

```js
{
  id: 't_xxxx',
  title: '한샘 김실장 통화 — 단가 확인',
  date: '2026-10-15',        // '' = 날짜 없음
  time: '13:00',             // '' | '오전' | '오후' | 'HH:MM'
  link: null | {             // 연결 대상 (없을 수 있음)
    type: 'client' | 'site' | 'service',
    id: 'c_… | s_… | AS id',
    siteId: 's_…',           // type=service 일 때 AS 가 들어있는 현장
    label: '한샘'            // 만들 때 이름을 같이 적어 둔다 — 대상이 지워져도 보이게
  },
  done: false,
  doneAt: 0,
  result: '',                // 끝낼 때 적은 결과 메모
  createdAt, updatedAt
}
```

- 연결 대상이 지워졌으면 `(지운 현장) 우륵 704` 처럼 `label` 로 보여주고 연결 동작(필름 목록 등)은 숨긴다.
- `normalizeTask` 가 모양이 이상한 값을 정리한다 (store.js 의 다른 normalize 와 같은 방식).

#### 1-2. 거래처 메모 내역 `client.notes[]` (거래처 객체 안)

```js
{ id: 'n_xxxx', date: '2026-10-15', text: '다음 주부터 단가 3% 인상…', kind: '통화' | '', taskId: 't_…' | '', createdAt }
```

- 최신이 맨 위. `normalizeClient` 가 없던 거래처에 `notes: []` 를 채운다.
- 거래처 객체 전체가 백업되므로 서버 변경 없음.

#### 1-3. 설정 `settings.taskRules`

```js
{ filmDays: 3, staffDays: 3, supplyDays: 1 }
```

`settingsForSync` 허용 목록에 `taskRules` 추가.

### 2. 자동 할 일 (저장하지 않음)

`Share.autoTasks(sites, today, rules)` — 순수 함수. 화면을 그릴 때마다 계산한다. 결과는 직접 넣은 할 일과 같은 모양(`auto: true`, `id` 는 `auto:종류:현장id[:AS id]` 로 고정)이라 같은 줄 그리기 함수를 쓴다.

| 종류 | 조건 | 날짜 칸 | 사라지는 때 |
|---|---|---|---|
| 필름 주문 | 시공 첫날까지 `filmDays` 일 이하 남음, `filmStageOf < 2`(미확정·확정) | 오늘 (시공 첫날이 지났으면 만들지 않음) | 단계를 '주문' 이상으로 |
| 인원 모집 | 시공 첫날까지 `staffDays` 일 이하, `staffTotal < needStaffOf` (기존 함수) | 오늘 | 인원 다 채움 |
| 부자재 준비 | 시공 첫날 또는 AS 날짜까지 `supplyDays` 일 이하, 현장 `supplies` 또는 AS `tools` 중 미체크가 있음 | 오늘 | 다 체크 |

- AS `tools` 에는 지금 체크 상태가 없다 → 할 일 창에서 체크할 수 있게 AS 에 `toolsReady: []`(체크한 이름 목록)를 추가한다. 기존 AS 는 빈 목록.
- 자동 할 일은 '오늘' 묶음에만 뜬다(미래 날짜에 미리 늘어놓지 않음). 지난 현장(첫날이 지남)은 만들지 않는다.

### 3. 일정 화면 (시안 B)

- `renderScheduleList` 의 기존 '현장 카드 + AS 카드 날짜순 섞기'(`mix`)에 할 일 묶음을 하나 더 섞는다. 같은 날이면 **할 일 묶음이 먼저**, 이어서 그날 시작하는 현장 카드·AS 카드.
  - 할 일 묶음 = 작은 날짜 머리줄 `10/15(수)` + 그날 할 일 줄들(시간 있는 것 시간순, 그다음 오전 → 오후 → 시간 없음).
  - 현장 카드는 여러 날에 걸친 '런' 단위다. 런 중간 날짜의 할 일 묶음은 그 런 카드 뒤, 다음 카드 앞에 날짜순으로 들어간다.
- 맨 위 순서: 고른 날짜 바(기존) → **밀린 할 일 상자**(빨강: 날짜 < 오늘이고 안 끝남) → AS 대기 상자(기존) → 지난 일정 접기(기존) → 오늘부터.
- 날짜 없는 할 일: 밀린 할 일 상자 아래 회색 '날짜 없음' 상자 (접힘, 건수 표시).
- 끝낸 할 일: 그날 아래 '완료 N건' 한 줄로 접힘. 지난 날짜의 완료는 '지난 일정' 을 펼쳤을 때만.
- 달력: 할 일이 있는 날 칸에 작은 점(주황). 기존 건수 배지는 현장·AS 만 센다(바꾸지 않음).
- 줄 모양: `☐ [아이콘] 13:00 제목  ·연결이름  [자동]`. 체크칸을 누르면 바로 완료(연결 없는 할 일). 줄을 누르면 할 일 창.

### 4. 넣기와 끝내기

**넣기 창** (`openTaskSheet(date?)`)
- 진입: 고른 날짜 바의 '일정 넣기' 시트에 '할 일' 버튼 추가 + 일정 화면 아래 떠 있는 `＋ 할 일` 버튼.
- 칸: 무엇을(필수) · 언제(오늘/내일/날짜 고르기/날짜 없음) · 몇 시(오전/오후/시각, 비워도 됨) · 연결(거래처/현장/AS 고르기, 비워도 됨).
- 현장 화면·거래처 화면에서 열면 연결이 미리 채워진다(현장 화면 머리 '＋ 할 일', 거래처 화면 메모 내역 옆 '＋ 할 일').

**할 일 창** (줄을 눌렀을 때) — 연결 종류마다 아래 내용이 더 붙는다.
- 공통: 제목·날짜·시간 고치기, 삭제, 결과 메모 칸, '완료' 버튼.
- 거래처: '완료' = 결과 메모가 있으면 그 거래처 `notes` 맨 위에 `{date: 오늘, text: 결과, kind: 제목에 '통화' 가 있으면 '통화', taskId}` 추가. '후속 할 일 만들기' = 같은 거래처 연결로 넣기 창 열기.
- 현장: 필름 줄 목록(시공위치·번호) + '번호 복사'(기존 `filmOrderText`) + '주문함' = 필름 단계 '주문'(2)으로 올리고 할 일 완료. 이미 '주문' 이상이면 버튼 대신 현재 단계 표시. 인원 부족이면 `staffShortLine` 한 줄과 '모집 문구 복사'(기존 공유 문구의 인원 부족 줄 + 현장명·날짜).
- AS: 부자재·공구 체크리스트(`toolsReady`).
- 자동 할 일 창: 위 연결 동작만 있고 제목·날짜 고치기/삭제/완료 없음 (조건이 풀리면 사라진다는 안내 한 줄).
- 완료 취소: 완료 묶음에서 다시 누르면 되돌림. 거래처 메모 내역에 이미 들어간 줄은 지우지 않는다(메모 내역에서 직접 지움).

**거래처 화면 메모 내역**
- 고정 메모 아래 '메모 내역' 칸: 맨 위 '직접 적기' 입력(엔터/추가 버튼 → 오늘 날짜로 쌓임), 아래로 최신순 목록. 할 일에서 온 줄은 '할 일에서' 표시. 줄을 길게 누르면 고치기/지우기.

### 5. 백업 (n8n·Airtable)

- Airtable "거래처별 현장관리" 베이스에 **'할일'** 표 추가. 칸은 다른 표와 같은 `id`, `data`(JSON), `수정시각`, `삭제` + 보기 편하게 `제목`, `날짜`.
- n8n "거래처별 현장관리 백업" 워크플로우 (181노드 `LGaXbJ6ESCOqYTg9` 아님):
  - `키검사·배치생성` 코드의 `TABLE` 에 `task: '할일'`, 필드 매핑에 `제목`·`날짜` 추가.
  - 복원 쪽에 '할일 읽기' Airtable 노드를 다른 '읽기' 노드와 같은 방식으로 추가하고, 응답에 `tasks` 를 붙인다.
  - 바꾸기 전 워크플로우 전체를 `n8n/` 폴더에 날짜 붙여 백업, 바꾼 뒤 비교. 저장소의 `현장관리_백업.template.json`·`build_workflow.py` 도 같이 고친다.
- 앱: `store.js` 에 `tasks()`/`addTask`/`updateTask`/`deleteTask`/`addClientNote`/`updateClientNote`/`deleteClientNote`, 큐 op `type: 'task'`. 복원 시 `data.tasks` 가 없으면(옛 서버) 폰의 할 일을 지우지 않고 그대로 둔다.

### 6. 이번에 하지 않는 것

알림(시간 되면 폰 울리기), 반복 할 일, 자동 할 일 '오늘만 숨기기', 팀원 공유, 할 일 검색, 관리자 앱 연동.
