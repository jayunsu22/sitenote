## 1. 원칙 (사장님과 합의)
- 뼈대는 **업무자동화**(정해진 규칙, n8n), 사람 말(카톡·문자·통화)을 읽는 곳만 **AI**, **돈·발주·업체에 보내기는 사장님 확인** 후.
- **카톡은 자동 발송하지 않는다** (개인 카톡 공식 API 없음, 알림 가로채기 봇은 약관 위반·계정 정지 위험). 읽기·정리는 자동, 보내기는 "📋 복사하고 카톡 열기".
- **문자는 안드로이드 폰을 발송기로** (SMS Gateway for Android, 클라우드 모드). 무료·사장님 번호·답장도 수신 → AI 가 해석. 유료 문자 API(알리고·솔라피) 안 씀.
- Jev(TypeSafe AI 의 분류 전용 모델, 얼리 액세스)는 지금 불필요. 메시지가 많아지면 앞단 거름망으로.
- 견적 초안은 **현장견적 앱(songil quote_pro) 저장함**에 저장.
- 사장님 환경: 윈도우 PC + PC 카톡 사용, 갤럭시(폴드/울트라로 교체 고민 중 — 기존 폰은 문자 발송폰으로 재활용 권장).

- **발행은 Claude 가 직접, 무조건 가견적.** 카톡은 **'김정헌' 방(= 나와의 채팅)에만** 써 넣고 **전송까지** 한다. pk디자인 등 실운영 방·고객 개인톡에는 절대 보내지 않는다. 보내기 전 창 제목이 '김정헌' 인지 확인.
- **금액이 바뀌는 빠진 정보는 먼저 묻고 견적.** (단, 문틀 여부는 이제 견적서의 [✓문짝][✓문틀] 체크로 고객이 직접 고를 수 있어 질문 생략을 검토 중 — 사장님 확인 전까지는 먼저 묻기.) 위치·날짜처럼 금액과 무관한 건 견적과 같이 물어도 된다.
- 어느 방인지 모르면 **첫 사진 = 방1**, 다음 사진 = 방2… 사진 부위를 모르면 사장님이 정해 준다.
- **사진은 Claude 가 카톡에서 저장해 품목에 붙인다** (사장님이 하지 않는다). 민자가 아닌 문(판넬·몰딩문)은 **난이도 1.2(+20%)** 하고 이유를 견적서 **메모**(고객에게 보임)에 적는다.
- 견적 제목(현장명) = **`위치 가견적 10월29일 오후8시(거래처)`**. 견적서에는 첫 줄 [가견적] 배지 + 위치, 둘째 줄 날짜 시 (거래처)로 보인다.

### 작업 방법 (도구) — 막혔던 곳
- **카톡**: 컴퓨터 사용. `open_application 카카오톡` 은 목록 창을 앞으로 가져오므로, 김정헌 채팅창 제목줄을 한 번 클릭해 앞으로 → 입력칸 클릭 → 한 줄로 입력(줄바꿈 금지, Enter=전송) → 전송 버튼. 입력칸을 잘못 누르면 목록 창의 '친구 추가' 가 열린 적 있음.
- **카톡 사진 저장**: 사진 더블클릭 → 뷰어 오른쪽 아래 저장 → '묶음사진 전체저장' → 문서\카카오톡 받은 파일.
- **내장 브라우저(Claude 앱 안)**: 파일 선택·클립보드·새 탭·confirm/prompt 가 **막힘** → 사진 붙이기 불가. 현장관리·견적 보기 확인용으로만.
- **사진 붙이기·발행은 크롬(Claude in Chrome)**: 사진을 세션 작업 폴더로 복사 → 품목 [사진] → 트레이의 숨은 `#trayPick` 을 잠깐 보이게 → `file_upload`. **크롬 작업 창이 가려지거나 최소화되면 클릭이 안 먹고 스크린샷이 멈춤** → 사장님께 그 창을 보이게 띄워 달라고 할 것.
- 크롬·내장 브라우저 모두 **처음 한 번**: 관리자 암호, 등록 링크(`…/autoblog/admin.html#key=…`, `…/settle.html#key=…` — 링크 주소만 복사), 백업키(숫자 6자리, `n8n/.backup_key` 파일 값은 옛 값이라 안 맞음). 지금 이 PC의 크롬·내장 브라우저는 등록 완료.
- 저장 버튼은 현장명이 비어 있으면 prompt() 를 띄움(내장 브라우저에서 막힘) → 현장명을 먼저 채울 것.

### 바뀐 작동 방식 (사장님 결정 10/30): '견적발행시작' 신호
- 노트북이 글이 조용해지면 바로 견적을 내던 방식은, 고객이 아직 글을 쓰는 중에도 견적을 낼 수 있어 오류 위험 → **사장님이 김정헌 방에 글·사진을 올리고 `견적발행시작 거래처명` 이라고 쓰면 그때 발행.** 그 묶음 = 지난 신호(또는 지난 링크) 뒤의 글·사진.
- **거래처 찾기**: 띄어쓰기·대소문자 무시, `config.json` 의 `client_aliases`(별명 → 진짜 이름). 비슷한 이름(pk디자인/ph디자인)을 짐작으로 고르지 않는다 — 틀린 업체에 들어가는 게 더 나쁨. 못 찾으면 현장관리 앱의 **'업체미확인' 거래처**(사장님이 [+] 로 만들어 둠)로 넣고, 사장님이 거기서 진짜 업체로 옮긴다 (현장관리 쪽 '거래처 바꾸기' 기능은 아직 — 할 일).
- **결과 알림 = 텔레그램**: 발행·실패·사진 못 저장을 텔레그램(기존 '견적서작성발송봇' 자격 `4iGW8eEwhNuTpFHa`, 챗ID 는 Airtable 가맹점 `p_001` 의 `텔레그램_챗ID`)으로.

### 앞으로: '비서' 구조 (사장님 합의 10/30, 아직 안 만듦)
사장님은 업체 카톡 알림을 모두 꺼 둔다. 견적 문의뿐 아니라 하자보수·일정연기·견적추가 등이 섞여 오고, 문자·전화까지 더하면 **일하는 시간보다 연락하는 시간이 많아지는 낭비**.
→ **연락은 한곳에 모으고 → AI 가 분류·요약 → 사장님은 결정만 → 처리는 프로그램.**
1. **(지금) 김정헌 방 '견적발행시작'** 마무리 — 연락함이 생겨도 사장님이 직접 견적을 넣는 길로 계속 씀.
2. **(다음) 모든 업체·고객 방 읽기 → 분류 → 텔레그램 요약** (카톡부터).
   - 노트북이 채팅 목록에서 **안 읽은 표시(숫자 배지)** 를 화면으로 찾아 그 방을 열어 글을 읽음. 빼는 방 목록(가족·개인)을 둠.
   - 분류: 견적 문의 / 견적 추가 / 하자보수(AS) / 일정 변경 / 결제 / 기타. 예 "pk디자인 · 일정 변경: 11/14 → 11/16 요청 (투나여행 현장)".
   - 분류·요약은 n8n 의 Gemini(나중엔 Claude API) — 건당 몇 원. 현장관리 앱의 📥 카톡 정리(AS·일정·비번 뽑기) 재사용 가능.
   - **결정 필요: 방을 열면 상대 카톡에 '읽음'(1 사라짐)이 생긴다** — 사장님 결정 대기.
   - 어려운 점은 토큰·보안이 아니라: 카톡 채팅 목록이 그림이라 화면 분석·마우스로 방을 열어야 함, 읽음 표시, 개인 방 빼기.
3. **(그다음) 텔레그램 버튼으로 결정 → 처리**: 예 "pk디자인 견적 문의 — 방문3, 샤시1, 사진 3장" + [가견적 발행] [나중에]. 노트북이 이미 그 방 글·사진을 가지고 있으니 버튼만 누르면 됨(김정헌 방 전달 불필요). 일정 변경 → [현장관리에 반영] [답장 초안]. 하자보수 → AS 등록.
4. **(마지막) 문자 → 통화녹음** 순서로 같은 연락함에: 문자는 4단계의 안드로이드 SMS 게이트웨이 앱, 통화는 갤럭시 통화녹음 → 글로 바꿔 넘김.
- **고객에게 보내는 건 계속 사장님 확인 뒤** (카톡 약관·정지 위험). 링크를 보내는 방은 지금도 김정헌 방만.
